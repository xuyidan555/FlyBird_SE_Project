# 🐦 Hust牌小鸟 (HustBird)

基于 Qt C++ 开发的桌面休闲游戏，复刻经典 Flappy Bird 玩法，并创新性地加入了自定义头像上传与裁剪系统。

## 🚀 快速开始

### 方式一：直接运行（推荐）

请在右侧 [Releases](https://github.com/xuyidan555/FlyBird_SE_Project/releases) 页面下载最新版本的 `FlyBird×.×.×.zip`，解压后双击 `flyBird.exe` 即可直接游玩，无需安装 Qt 环境。

### 方式二：源码编译

1. 确保本地已安装 Qt 5.15 及以上版本（MinGW编译器）。
   
2. 克隆本仓库到本地。
    
3. 使用 Qt Creator 打开 `flyBird.pro`。
    
4. 选择 Debug/Release 模式进行构建并运行。
